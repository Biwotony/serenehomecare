# Serene Home Care Services

Public website for Serene Home Care Services in Eldoret, Kenya.

## Local development

```bash
npm run install:ci
npm run dev
```

## Checks

```bash
npm run lint
npm test
npm run validate:artifact
```

## Content that must be verified before public launch

- legal registration and licence details where applicable
- named leadership and staff biographies, qualifications and registrations
- exact physical address and confirmed opening hours
- authentic family reviews with documented publication consent
- final legal review of the privacy notice and payment terms

The website deliberately does not invent these details. Initial enquiries open in WhatsApp and do not request medical history or payment information.
